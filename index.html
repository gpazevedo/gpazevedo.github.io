25+ years architecting distributed systems. I work across the whole stack of a real system: agent orchestration on Amazon Bedrock AgentCore and the Strands Agents SDK, multi-tenant runtimes, MCP integrations with enterprise platforms (SAP S/4HANA, Oracle Fusion, Coupa), and the observability, evaluations, security mapping, IaC, and GitOps that production multi-tenant operation actually requires.
